**Java** game that is inspired by the game Scrabble 
Player plays against the computer to form valid words to try and get
the highest scoring word.

**How to run:**
-Download from releases
-If zip file was downloaded, unzip/extract
-Open your terminal and type in: 
java -jar Scrapple.jar

**What I learned:**
-how to use java string methods with a for loop to select tiles from the
tile pool to add to the player's hand
-how to use Math.random() to randomly select tiles for a player's/computer's hand

**What I struggled with:**
-In word utils the whole dictionary file is in lowercase but I accidentally made my Scrapple word
pool uppercase 
-This caused an error in the game
-To fix the error I added toLowerCase() in various spots in Scrapple so that the cases matched.
